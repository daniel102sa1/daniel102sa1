### 🛠️ Ferretería El Campesino

Sistema comercial compuesto por una API REST, una plataforma web administrativa y una aplicación móvil nativa para Android.

#### Componentes desarrollados

- Backend construido con Python y FastAPI.
- Plataforma web desarrollada con Next.js, React y TypeScript.
- Aplicación Android desarrollada con Kotlin y Jetpack Compose.
- Integración de las aplicaciones con una API REST.
- Autenticación de usuarios y manejo de sesiones.
- Almacenamiento local de sesión mediante DataStore.
- Navegación y estructura para productos, clientes, ventas, inventario, proveedores y reportes.
- Conexión móvil al backend mediante Retrofit.
- Organización de la aplicación Android con arquitectura MVVM.

#### Tecnologías

`Python` `FastAPI` `PostgreSQL` `Next.js` `React` `TypeScript` `Tailwind CSS` `Kotlin` `Jetpack Compose` `Retrofit`

> El código fuente se mantiene privado porque corresponde a un sistema comercial. Se pueden presentar capturas y una demostración durante una entrevista.
